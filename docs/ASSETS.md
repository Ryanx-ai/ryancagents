# Character assets

`public/assets/maple-ryan.png` is Ryan’s supplied Maple Ryan pet atlas, preserved in its original 1536×2288 layout (8 columns, 11 rows, 192×208 cells). Idle, walking, working, waiting and jumping use its existing frames.

`public/assets/manager-ryan.png` was generated with OpenAI image generation on 26 November 2026, using the supplied Ryan character as the visual reference. Edit direction: preserve Ryan’s face, swept dark hair, skin tone, chibi proportions and pixel-game style; dress him in a black suit and white polo; full body, transparent background, no labels or scene. The manager uses a single transparent pose animated in CSS for walking, working and celebration. It is not a replacement for the original pet atlas.

The office is original SVG art. The look references side-view platformers and a warm Singapore office, without importing commercial game assets.
